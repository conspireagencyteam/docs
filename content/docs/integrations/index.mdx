Bonde connects to a few tools your team already runs. Each one is connected from **Settings** in Bonde and can be disconnected there at any time.

## Gorgias

Gorgias is Bonde's helpdesk integration. When a shopper writes in, your support agents see every subscription that shopper has in the ticket sidebar, with buttons to skip, pause, resume, cancel, reschedule, discount or send a payment update link without leaving Gorgias. If you use Gorgias AI Agent, it can do the same work on its own, within the permissions you set. Gorgias is included in Bonde Pro ($15 a month flat, no transaction fees).

## Klaviyo

Connect Klaviyo so Bonde can read your email performance alongside your Shopify data. Go to **Settings > Klaviyo**.

## Recharge

Connect Recharge so the cart sidebar can offer Subscribe and save using your existing Recharge plans. Go to **Settings > Recharge**.

## Other helpdesks and custom tools

The Gorgias integration is built on the Bonde Connect API, a small HTTP interface that looks up a shopper's subscriptions by email and runs the same actions your agents have in Gorgias. Any helpdesk or internal tool that can send an HTTP request with a header can use it, with the same permissions and the same timeline entries in Bonde. See the [Connect API reference](/docs/integrations/connect-api).
